# CropNet AI — Soil Data Source Licensing & Access Risk Register

| Risk ID | Source / Provider | Nature of Risk | Severity | Verification Status | Mitigation & Architectural Strategy |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **RISK-01** | **ISRIC SoilGrids 2.0** | Rate limiting or temporary downtime of public WCS server (`maps.isric.org`). | Medium | **VERIFIED OPERATIONAL** (CC BY 4.0; 2–4s response time). | Implement backend bounding box caching; fallback to cached regional GeoTIFFs via `LocalRasterProvider`. |
| **RISK-02** | **OpenLandMap (OpenGeoHub)** | High network latency and read timeouts when streaming 186 GB global COG mosaics over HTTP from Wasabi S3 in Europe. | High | **VERIFIED ACCESS; LATENCY RISK IDENTIFIED** (CC BY 4.0). | Avoid querying 186 GB remote rasters on live synchronous requests. Mirror pilot district clips (Pune/Maharashtra) into local storage (`data_cache/`). |
| **RISK-03** | **ICAR-NBSS&LUP BHOOMI** | Geoportal GeoServer blocks public unauthenticated access (**HTTP 403 Forbidden**). Institutional partnership or formal access agreement required. | High | **VERIFIED BLOCKED FOR PUBLIC ACCESS**. | Keep integration strictly modular via `BhoomiProvider`. Do not make MVP dependent on institutional credentials or approval. |
| **RISK-04** | **NATMO Geoportal** | Server instability (**HTTP 500: Service unavailable**). Cartographic visualization only (no WCS or numerical GIS extraction). Strict Govt copyright. | High | **VERIFIED NON-OPERATIONAL FOR GIS EXTRACTION**. | Do not use NATMO for numerical soil parameter extraction. Mark provider as disabled. |
| **RISK-05** | **Misinterpretation of Total N as Available N** | Farmer or downstream crop model treating Total Nitrogen (e.g. 2.1 g/kg = 2100 mg/kg) as available mineral N, leading to catastrophic fertilizer errors. | Critical | **PREVENTED VIA CODE GUARDS**. | Hard-block conversion of Total N to available N. Enforce `available_nitrogen = null` with explicit `NOT_AVAILABLE` status and clear explanatory warning. |
| **RISK-06** | **Fabrication of Available NPK** | Recommender engine requiring NPK values, prompting developers to inject placeholder or average NPK. | Critical | **PREVENTED VIA SCHEMA & ENGINE DESIGN**. | CropNet recommendation engine implements **Mode A (Map-Based Suitability)** which relies solely on soil texture, pH, depth, organic carbon, and climate without requiring NPK. |
| **RISK-07** | **False Equivalence to Lab Tests** | Farmers relying on map-derived 250m pixels as certified physical laboratory soil test results. | Critical | **PREVENTED VIA UI DISCLAIMERS**. | Every screen and API response displays the mandatory disclaimer: *"Map-Derived Estimate: These values are derived from digital geospatial soil models and are NOT physical laboratory measurements."* |
