# RASHKAR — Official Hackathon Presentation Requirements Traceability Matrix

**Presentation Title:** RASHKAR — AI platform predicting farm level heat risk and verifying plot level crop loss for Indian smallholders  
**Competition:** PCCOE International Grand Challenge 2026, Theme: AI for Climate Change  
**Team Members:** Vernit Garg, Siddhesh Birewar, Shubham Pokale, Disha Doshi  
**College:** Pimpri Chinchwad College of Engineering, Pune (B.Tech CSE-AIML)  
**Date of Audit:** November 2026  
**Status Legend:**
- `COMPLETE_VERIFIED`: Requirement fully implemented, integrated across backend and frontend, and verified by automated tests.
- `PARTIALLY_IMPLEMENTED`: Core logic exists in backend or frontend, but requires PPT-aligned enhancements (e.g., adding multi-index, 0–100 score dial, 48h SLA timer).
- `MISSING`: Proposed capability not yet present in codebase.
- `BLOCKED_EXTERNAL_DATA`: Capability requires proprietary, licensed, or live institutional APIs not freely available during prototype development (e.g., live official PMFBY National Crop Insurance Portal API, live commercial drone streams); handled via documented open proxies and honest disclosure.
- `PROPOSED_FUTURE`: Long-term institutional roadmap item explicitly slated for post-pilot phases (e.g., 10+ Indian languages, pan-India expansion).

## Strategic Action Plan

To transition all `PARTIALLY_IMPLEMENTED` requirements into `COMPLETE_VERIFIED`:

1. **Thermal Indices & Personalization Engine (`backend/app/services/thermal_indices_service.py` & `backend/app/ml/heat_ml_pipeline.py`):**
   - Implement NOAA Heat Index (Rothfusz equation) with high/low temperature-relative humidity adjustments.
   - Implement Universal Thermal Climate Index (UTCI) 6th-order polynomial approximation.
   - Implement topographic lapse-rate elevation downscaling ($\Delta T = -6.5^\circ\text{C}/\text{km} \times \Delta h$) from the 11 km base grid to the 1 km target plot.
   - Implement 30-minute cadence caching (`ForecastGridCache`) with geographic grid rounding ($0.1^\circ \approx 11\,\text{km}$) shared across nearby farms.
   - Implement explainable 0–100 composite Personalized Heat Strain Score for workers and 0–100 Crop Heat Vulnerability Score.
   - Stage XGBoost forecast and Random Forest personalization models with documented metrics (MAE, RMSE, $R^2$) and model cards.

2. **PMFBY Multimodal Vision & Loss Verification Engine (`backend/app/services/pmfby_vision_service.py`):**
   - Implement Sentinel-2 pre- vs. post-event spectral vegetation index analysis (NDVI, NDWI, EVI anomaly detection) over plot boundaries.
   - Implement vision damage classification (YOLOv8 damage detection, U-Net plot segmentation, and ViT feature extraction contracts).
   - Implement multimodal evidence fusion calculating plot loss percentage and a calibrated confidence score (0–100%).
   - Implement 48-hour SLA countdown tracking for claim verification.

3. **Flutter Web Frontend Alignment:**
   - **`HeatSafetyScreen`:** Add 0–100 Personalized Heat Risk dial, multi-index comparisons (WBGT, Heat Index, UTCI), 30-minute refresh countdown badge, and 1 km downscaling disclosure.
   - **`CropLossScreen`:** Display plot polygon satellite pre/post NDVI comparison, YOLOv8/ViT damage classification breakdown, and multimodal claim evidence dossier.
   - **`InsurerDashboardScreen`:** New dedicated screen for agricultural insurance reviewers to inspect pending claims (<48h SLA timer), review multimodal evidence, and submit binding decisions.
   - Update navigation and drawer to give instant access to the Insurer Dashboard.

4. **Testing & Verification:**
   - Add comprehensive Pytest suite `backend/tests/test_ppt_alignment.py`.
   - Verify all tests pass, verify Flutter builds cleanly, and record Playwright browser screenshots.
